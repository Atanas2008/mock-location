# mock-location

## Симулиране на GPS локация на iPhone с Windows

Тази папка съдържа помощни `.bat` файлове за iOS 17 и по-нова версия. Те използват
`pymobiledevice3` и изискват собствен iPhone, Developer Mode и надеждна USB връзка.
Посочените координати в `start_location.bat` са примерни полета за попълване, не
готова локация.

### Подготовка

1. Отворете **Command Prompt** и проверете Python и pip:

   ```bat
   python --version
   python -m pip --version
   ```

   Ако `python` не е намерен, инсталирайте Python 3 от
   [python.org/downloads/windows](https://www.python.org/downloads/windows/) и отбележете
   **Add python.exe to PATH** в инсталатора. Затворете и отворете отново Command Prompt,
   после повторете двете проверки.

2. Инсталирайте или обновете `pymobiledevice3`:

   ```bat
   python -m pip install -U pymobiledevice3
   ```

3. Инсталирайте iTunes или Apple Devices, така че да са налични Apple драйверите. Ако
   устройството не се открива, проверете дали Apple Mobile Device Service работи; класическият
   инсталатор на iTunes често е по-надежден за откриване през USB.

4. Свържете отключения iPhone с USB кабел, натиснете **Trust / Доверие** на телефона и
   въведете кода му. Проверете връзката и версията:

   ```bat
   python -m pymobiledevice3 usbmux list
   ```

   В изхода намерете `ProductVersion` за телефона. Ако устройството липсва, проверете кабела,
   драйверите и Trust преди да продължите.

5. Ако Developer Mode не е включен, изпълнете:

   ```bat
   python -m pymobiledevice3 amfi reveal-developer-mode
   ```

   Следвайте указанията на телефона: отворете **Settings → Privacy & Security → Developer
   Mode**, включете режима, потвърдете рестартирането, а след рестарта потвърдете включването
   и отключете телефона. Ако тази команда не е налична във вашата версия, обновете
   `pymobiledevice3`; при нужда включете режима ръчно от същото меню.

### Стартиране и спиране

За iOS 17 или по-нова версия:

1. Отворете `start_location.bat` с Notepad и заменете `YOUR_LATITUDE` и `YOUR_LONGITUDE`
   с десетични координати (ширина от -90 до 90, дължина от -180 до 180).
2. Стартирайте `start_location.bat`. Потвърдете UAC заявката, за да се отвори отделен
   администраторски прозорец за тунела. Не затваряйте този прозорец, докато използвате
   симулираната локация.
3. Скриптът монтира подходящото Developer Disk Image и задава локацията. При iOS 17.0–17.3.1
   Windows изисква работещ тунел с администраторски права. При по-нови версии CLI може сам
   да създаде тунел; скриптът използва стартирания тунел.
4. Оставете отворени прозореца на скрипта и администраторския прозорец, докато симулацията
   е активна. За връщане към истинската GPS локация стартирайте `stop_location.bat` в нов
   прозорец. След това натиснете Enter в първия прозорец и затворете администратора.

За **iOS под 17** не използвайте тези скриптове: отворете Command Prompt и изпълнете:

```bat
python -m pymobiledevice3 developer simulate-location set -- LAT LON
```

Заменете `LAT` и `LON` с координати. За изчистване изпълнете:

```bat
python -m pymobiledevice3 developer simulate-location clear
```

Тези по-стари версии не използват командата `developer dvt`.

### Грешки и проверка

- Ако командата `python` не работи, проверете инсталацията и PATH, после отворете нов Command
  Prompt.
- Ако `usbmux list` не показва iPhone-а, отключете го, проверете кабела/драйвера и натиснете
  **Trust**. Ако няма диалог, проверете **Settings → General → Transfer or Reset iPhone →
  Reset → Reset Location & Privacy**; това нулира избора за Trust и следващото свързване
  ще го попита отново.
- Ако се изисква Developer Mode или Developer Disk Image, изпълнете съответно командата от
  подготовката или `python -m pymobiledevice3 mounter auto-mount`, после опитайте отново.
- При грешка за тунел проверете дали администраторският прозорец още работи. Ако грешката
  продължи, копирайте точния текст и версията на iOS.
- Проверете резултата в приложение, което показва текущата локация. В документацията на
  `pymobiledevice3` няма гаранция по версия на iOS, че симулираната локация ще остане след
  разкачане на кабела, затова не разчитайте на това. Тествайте, като разкачите USB и проверите
  отново същото приложение; свържете телефона пак и изпълнете `stop_location.bat`, за да
  изчистите симулацията.
